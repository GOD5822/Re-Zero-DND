# Re:Zero DnD V4

Custom 5e-inspired homebrew for *Re:Zero − Starting Life in Another World*.

**Core resolution:** `5d4 + floor(stat/3)` — **no roll caps**.  
**Max HP:** `220 + Fortitude + Vitality Bonus`  
**Max Sanity:** `100 + Willpower`  
**Power:** `floor(max(total allocated stats − 40, 0) / 15)`  
**Weapon scaling:** `50% + 1.5% × Weapon Proficiency` (capped at WP 100 → 200%)
